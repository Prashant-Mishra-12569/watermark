Watermark Tap (Android) goes here as: watermark-tap.apk

The site's /app page checks for web/public/download/watermark-tap.apk on every request.
While the file is missing it shows "The Android app is being published" instead of a
download button. Once the file is here, the page shows the download button, the file
size and a QR code for https://usewatermark.xyz/download/watermark-tap.apk.

*.apk is ignored by git, so copy the file onto the machine that serves the site.
